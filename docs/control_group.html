3 Variable Dictionary

Source (RPDR Dem.txt) In Code Derivation
EMPI EMPI Unique patients from Dem.txt
First neoplasm Dx date (Dia.txt) Index_date First ICD10 C00–D49 diagnosis date
Date_of_Birth Date_of_Birth Used to derive Age
Gender_Legal_Sex Gender_Legal_Sex Used to derive male
Race1 Race1 As-is
Ethnic_Group Ethnic_Group As-is
Date_Of_Death Date_Of_Death Used to derive death, time_to_death
Last CRE date (Lab.txt) last_cre_date Derived: last CRE lab date per patient

Derived variables

Variable Description
Age floor((Index_date − Date_of_Birth) / 365.25)
male 1 if Male, else 0
last_cre_days Days from Index_date to last_cre_date
death 1 if Date_Of_Death is not NA
time_to_death Date_Of_Death − Index_date (days), or last_cre_days if alive
death_Xyear (1–10) 1 if died within X×365 days
survival_Xyear (1–10) 1 if last_cre_days ≥ 365×X
pre_median_CRE_90days Median CRE ≤90 days pre-index (RPDR)
eGFR_CRE_baseline CKD-EPI 2021 from baseline CRE
ckd_stage_baseline CKD stages 1–5
ckd_stage_baseline_3 3-level: stage 1 / stage 2 / stage 3 or more
pre_median_CRE_Xyear (1–10) Yearly median CRE (90-day window)
eGFR_CRE_Xyear (1–10) Yearly eGFR
ckd_stage_Xyear (1–10) Yearly CKD stage
lab_num_Xyear (1–10) Number of CRE labs in yearly window

Matching variables (CRE measurement counts)

Variable Description
n_cre_pre_1yr Count of CRE labs in [Index_date − 365, Index_date) — primary matching variable
n_cre_pre_all Count of all CRE labs before Index_date
pre_history_days Days from earliest pre-index CRE lab to Index_date (0 if none)
cre_rate_pre n_cre_pre_all / (pre_history_days / 365) — NA if no pre-index history
has_pre_cre 1 if n_cre_pre_1yr > 0, else 0
n_cre_post Count of CRE labs in (Index_date, last_cre_date] (covariate, not for matching)
cre_rate_post n_cre_post / (last_cre_days / 365) — NA if last_cre_days ≤ 0

Inclusion criteria

Criterion Description
Baseline CRE ≥1 creatinine within 12 months prior to Index_date
Follow-up ≥18 months (548 days) of follow-up from Index_date
Post-index CRE ≥2 creatinine results after Index_date

Follow-up uses last_cre_date → last_cre_days for censoring.
