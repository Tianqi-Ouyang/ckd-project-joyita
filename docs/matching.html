Propensity-Score Matching – Treated vs Control

Author

Tianqi Ouyang

Published

April 15, 2026

Summary

Rationale

Treated (ICI, n=379) and control (non-ICI neoplasm, n=1,307) cohorts differ on demographics, calendar era, comorbidity profile, baseline kidney function, and — critically for outcome interpretation — baseline creatinine surveillance intensity (n_cre_pre_1yr). A direct comparison would confound the ICI effect with differential measurement, follow-up, and practice-era effects. Propensity-score matching is used to construct a comparable control subset while retaining all 379 treated patients.

Method

Parameter Value
Matching algorithm Nearest-neighbor PS matching (logit PS), greedy, no replacement
Ratio Variable 1:k, ratio = 2 (target mean), min.controls = 1, max.controls = 3
Caliper 0.2 × SD(logit PS)
Exact-match stratum era (2016–2019 / 2020–2023)
Eligibility filter has_pre_cre == 1
Seed set.seed(42)
Software R MatchIt 4.x
Balance target Standardized mean difference (SMD) < 0.1 for all PS model covariates

Key design choices

Choice Reason
Drop pre-2016 controls Treated cohort begins 2016; earlier controls have no temporal counterpart
Variable 1:k matching with ratio=2, min.controls=1, max.controls=3 Allows up to 1:3 in the early era where controls are abundant; falls back to 1:1 in the late era (2020–2023) where controls are scarce. Keeps all 379 eligible treated patients in the matched cohort.
Caliper 0.2 × SD(logit PS) Austin (2011) — empirically optimal for bias removal
Exact-match on era only Era shift is large/structural; sex balances adequately via PS alone
Include n_cre_pre_1yr in PS model Surveillance intensity is a study-specific candidate confounder; must be balanced explicitly
Use binary white (1 = White, 0 = other) instead of multi-level Race ≥96% of both cohorts are White; treating Race as a 4-level factor wastes degrees of freedom on near-empty cells. The binary form captures all of the between-group variation that exists.
Exclude Ethnic_Group from PS model Highly collinear with Race/white after harmonisation and contributes little independent variation
Exclude pre_history_days from PS model Largely redundant with n_cre_pre_1yr; including both inflates the PS model without improving balance
Exclude Cancer_Diagnosis / Cancers_stage Control cohort lacks these fields (only treated has them)
Exclude pre_median_HGB_90days, pre_median_ALB_90days from PS model High missingness in controls (routine pre-ICI oncology workup labs are rarely drawn in the control pool); presence would leak treatment status. Shown in Table 1 for transparency only
Exclude post-exposure variables (last_cre_days, aki, outcomes) Would induce collider bias if included

Note on the 2020–2023 era

Within the 2020–2023 stratum the eligible counts are roughly 1:1.4 (treated 142 vs control 192), so a fixed 1:3 match is structurally infeasible — there simply aren’t 426 controls available. The variable-ratio specification handles this automatically:

  • 2016–2019 era: target up to 1:3 (control supply is plentiful at 777).
  • 2020–2023 era: most treated patients will receive 1:1 matches because min.controls = 1 is the binding constraint once the closest controls are consumed.

This is the right behaviour for this study — it preserves all treated patients, keeps the closest-PS controls in each era, and accepts a smaller k where the data demand it. The downstream Cox / competing-risk model uses subclass-clustered SEs (or MatchIt weights), so unequal cluster sizes are handled correctly.

10 Notes and caveats

  • Unmatched treated: any treated patient not matched is reported in §6; if >5%, revisit the caliper or widen era bins.
  • Sex not exact-matched: balanced via PS model alone. Check post-match SMD for male in §7; if >0.1, add exact = ~ era + male.
  • Cancer type / stage are only captured for treated patients and so cannot enter the PS model. Residual confounding by cancer type is a study limitation — address in the Discussion.
  • Post-exposure variables (last_cre_days, aki, any *_Xyear outcome) are excluded from the PS model to avoid collider / post-treatment bias.
  • Use of matched cohort downstream: Cox / competing-risk models should either (a) use the matched sample with robust/cluster-adjusted SEs by subclass, or (b) use weights from match.data() in a weighted outcome model.
